# personal-workstation

黄铭语个人数字工作站（Mingyu Personal Workstation）

一个面向个人展示、学术研究、知识管理与 AI Skill 工作流沉淀的个人数字工作站。

## Planned Modules

- Dashboard 工作台
- Profile 个人信息
- Projects 研究项目
- Publications 学术成果
- Knowledge Base 知识库
- Skills Library 个人 Skill 库
- Calendar 个人日历
- Documents 文件中心
- Settings 设置

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

## Status

Initial setup. The first MVP will be implemented with Codex.
